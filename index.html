My APIs

          Add any API you like. Use {query} in the URL where the AI's search goes, and {key} where your key goes (or pick a header). The AI is told each API's name and what it's for, and calls it when it fits.
          

          No custom APIs yet.
          

          Image generation uses Pollinations. Real-image lookup uses TVMaze, Openverse and Wikimedia Commons first, with optional Pexels, Pixabay and TMDB. Extra tools include YouTube, Wikipedia, Jikan anime, Open-Meteo weather, REST Countries, Frankfurter currency rates and OpenStreetMap places. YouTube/TMDB keys are optional. Keys are stored only in this browser. Web search opens DuckDuckGo results in a new tab.

Tools (MCP)

          
          
          

          

          
   

          
Paste a config (JSON with “mcpServers”) 

          Tool servers are programs that run on this computer (or web services) and can read files or change things. Only add ones you trust, and keep “ask me before each tool” on until you do. The model must support tool calling; if it doesn’t, chat simply works without tools. Text a tool returns can contain instructions from strangers (for example a web page): check what the AI asks to run. Programs started with npx need Node.js; uvx needs uv.

Live chat

          
          
          
          
          
          
          
          
          Press Live chat, say the wake word, then talk normally: it answers out loud and listens again without needing the wake word. After the quiet time above, or if you say “goodbye” or “that’s all”, it goes back to waiting for the wake word. Tap the orb to talk without it. Turn the wake word off to get the old behavior, where it listens right away. Speaking over a reply stops it so you can talk; headphones work best, because speakers can make it hear itself.
          
          Voice settings apply right away. In the IcyWhite app the microphone is transcribed on this computer by Whisper; the speech model (about 40 MB) downloads once the first time you use Dictate or Live chat, then works offline. Voices marked “online” are processed online.
