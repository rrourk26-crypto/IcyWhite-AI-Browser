# IcyWhite voice commands (hands-free live chat)

Start live chat (the waveform button), then talk. If it says *Waiting for “computer”…*, begin with the wake word (change it in Settings > Voice, or say *change the wake word to jarvis*): **“Computer, dark mode.”** After the first command you can keep talking without it until you are quiet for a while.

Say each command as one short sentence. Politeness is fine (*please*, *can you*, *for me*, *thanks*). The lines under **Say** are different natural ways to ask for the same thing. A normal sentence that only *contains* these words (“turn on the light in the kitchen”) is never taken as a command; it goes to the AI.

You can also see this list inside the app: **say “what can I say”**, or Settings > Voice > *Voice commands…*. Say **“help with settings”** (or chats, tabs, volume, models, switches, camera, approvals) to hear one group read aloud.

## Live chat basics

| Say (any of these) | What it does |
|---|---|
| “computer” | Wake word: starts a conversation (you can change the word). Then talk normally. |
| “goodbye”<br>“that's all”<br>“go to sleep”<br>“stop listening” | Ends the conversation. It waits for the wake word again. |
| “end live”<br>“stop live chat”<br>“turn off live mode” | Leaves live chat completely and turns the microphone off. |
| “stop”<br>“wait”<br>“hold on”<br>“be quiet” | Interrupts the reply while it is thinking or speaking (you can also just talk over it). |
| “keep listening”<br>“stay awake”<br>“stay on” | Stops the silence timer from ending live chat. |
| “help”<br>“what can I say”<br>“voice commands” | Opens the list of voice commands and tells you the main ones. |
| “help with settings”<br>“help with chats” | Reads the commands of one group. |
| “close help” | Closes the list. |

## Good to know

- **Anything that runs code or deletes asks first.** *Run the command*, *delete that reply*, *delete this chat* and *close all other tabs* read back what they will do and wait for *yes* or *no*.
- **Operating-system windows can't be spoken to.** *Attach a file*, *open a project folder* and *share my screen* open the normal Windows picker; choosing there needs the keyboard or mouse. Windows tools that ask Yes/Cancel (Registry Editor etc.) use a system dialog as well.
- Switches that live in Settings (web search, memory, compact mode, commands...) are changed and **saved automatically** when you say them while Settings is closed. If Settings is already open, say *save settings*.
- If a command isn't understood it is simply sent to the AI as a normal message, so nothing is lost.
- Works with the built-in offline speech engine (Whisper) and the browser's own recognizer. Short, clear sentences are recognized best.
